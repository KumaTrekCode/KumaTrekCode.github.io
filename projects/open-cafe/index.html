Open cafe（静的サイト）

デイトラの卒業課題として制作した、カフェ「Open cafe」向けランディングページの静的コーディング版です。デザインカンプをもとに HTML / CSS で組み立て、GitHub Pages 上のこのリポジトリで公開しています。

概要

課題の目的は、お店の魅力（コンセプト・メニュー・アクセスなど）を一枚のサイトで伝え、来店や問い合わせにつなげることです。画像・タイポグラフィ・余白のバランスをカンプに寄せながら、セマンティックなマークアップと保守しやすいクラス設計を意識しました。

本ページはポートフォリオ用の説明・入口です。実際のマークアップ一式は projects/open-cafe/site/ に配置し、同梱の site/index.html から閲覧できる形にしています。

使用技術・体制

HTML5、CSS3（カンプ準拠のレイアウト・レスポンシブ）、Git / GitHub Pages。

仕上げの微調整やアセット差し替えは、学習の進行に合わせて更新していきます。

プレビュー

静的サイトを開く（site/index.html）

成果物のファイルをまだコピーしていない場合は、プレースホルダ画面が表示されます。ビルド済みの index.html と CSS・画像を site/ に置き換えてください。

※ 本サイトで使用している一部のアイコン画像は、Gemini（生成AI）を用いて作成しています。
