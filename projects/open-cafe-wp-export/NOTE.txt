このフォルダーの用途
--------------------
Local WordPress（テーマ KUMA_DYA36_Open-Cafe）から、ブラウザの「名前を付けて保存」などで取り込んだ
静的 HTML・CSS・JS・画像を、まずここに集めてください。

既存のデイトラ用静的コーディング（教材ベース）は projects/open-cafe/ です。
こちら（open-cafe-wp-export）は WP 環境に近い見た目の書き出し置き場です。

初めてこの配下に .html を置いて npm run sync する場合は、
tools/sync-html-allowlist.json にパスを追加してください（本リポジトリでは追加済み）。

index から他ページへリンクがある場合は、gh-pages-static 内の該当 *.html もまとめてコピーしないと
ローカル・GitHub Pages でリンクが切れます。`tools/lint-links.mjs` の entryPoints には
`projects/open-cafe-wp-export/index.html` を **追加済み**（`npm run lint:links` / `npm run check` で検査）。

WP 書き出しは html-validate の厳格ルールと相性が悪いことがあるため、package.json の validate 対象外にしています。

index.html には、ポートフォリオ用に次を手で入れています。WP から index を差し替えたら、HTML コメント
「KumaTrekCode:」付近を目印にコピーして再貼り付けしてください。

  - head 末尾付近: 注意帯用の style#kuma-demo-disclaimer-style
  - body 直後: デイトラ課題デモである旨の p.kuma-demo-disclaimer
  - </body> 直前: 紹介ページへ戻るリンク（style + div）
