# Open cafe — WordPress 書き出し（参考用）

このディレクトリは、学習カリキュラム用に **WordPress から書き出した静的 HTML** を置いています。**本サイトの「正」としてメンテするページではありません**（説明・導線は `projects/open-cafe/index.html` 側を優先してください）。

## データについて

- 掲載されている住所・メール・電話などの連絡先は **ダミー／テンプレ用** の想定です。実在する個人や店舗を指すものではありません。
- 地図埋め込みなども **教材用のサンプル** です。

## a11y 補助スクリプト

`<dt>` / `<dd>` のマークアップ修正が必要な場合は、リポジトリルートで次を実行します（詳細はルート `README.md`）。

```bash
npm run fix:wp-export-a11y
```
