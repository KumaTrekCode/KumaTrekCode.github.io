# Portfolio site / ポートフォリオサイト

## English

Static HTML portfolio: home, blog posts as individual files, and a sample project page (**Open cafe**). Styles live in `css/style.css`. Explanatory copy on pages uses paired **EN** and **JA** blocks so you can edit both languages in one place.

**Run locally:** open `index.html` in a browser, or serve the folder with any static server (for example `npx serve .` from this directory).

**GitHub Pages:** put these files at the repository root (or under `/docs` if you use the `docs` publishing option). Enable **Settings → Pages** when you are ready to go public. Replace placeholders such as `YOUR_TWITTER_HANDLE` and “Your Name / あなたの名前”.

---

## 日本語

静的 HTML のポートフォリオです。トップ・ブログ（HTML を1ファイルずつ追加）・サンプル案件ページ（**Open cafe**）があります。スタイルは `css/style.css` です。各ページの説明は **EN** と **JA** の並記ブロックにしてあるので、同じ場所で両言語を編集できます。

**ローカル表示:** `index.html` をブラウザで開くか、このフォルダを任意の静的サーバで配信してください（例: このディレクトリで `npx serve .`）。

**GitHub Pages:** リポジトリのルート（または `docs` 公開を使う場合は `/docs`）にこの一式を置き、公開するときに **Settings → Pages** を有効にします。`YOUR_TWITTER_HANDLE` や「Your Name / あなたの名前」などのプレースホルダは自分用に置き換えてください。
