# プロダクト／アプリ案（アイデア正本）

> 公開サイト本文ではない。**新規アプリ・プロダクトのアイデアを記録・保管する正本**。  
> Cursor 等に渡すときは、このフォルダを文脈に含めてよい。

## 契約（エージェント向け・最優先）

1. **アイデアを勝手に実装しない** — ここに書いた案は記録のみ。コード生成・技術検証・リポジトリへの実装着手は行わない。
2. **`ROADMAP.md` の Agent queue に勝手に昇格しない** — 実装可能タスクへの切り出しは **人間** が完了条件つきで行う。
3. **既存の学習メモ方針・ロードマップ方針は変えない** — 追記は「新規アイデアの追加」に限る。

| 置き場 | 役割 | エージェント |
|--------|------|----------------|
| `docs/ideas/`（ここ） | プロダクト／アプリ案の保管 | **記録・整理のみ。実装しない** |
| `docs/learning/` | 学習・キャリア壁打ち | 参照可。勝手に完了チェックしない |
| `ROADMAP.md` | 実装・検証できるタスク | キューから1件だけ実装 |

## 使い方

1. 新しい案が出たら `docs/ideas/<slug>.md` を追加（または既存ファイルへ追記）
2. この README の **一覧** に1行足す
3. 冒頭に「アイデア段階／実装しない」を明示する
4. 実装したくなったら、人間が完了条件つきで [ROADMAP.md](../../ROADMAP.md) へ昇格する（昇格するまでエージェントは手を付けない）
