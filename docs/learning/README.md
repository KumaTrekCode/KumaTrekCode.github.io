# 学習メモ（履歴）

> 公開サイト本文ではない。**自分用の収集・勉強・キャリア整理**。動画や覚書から得た要点を残し、[roadmap-wall.md](./roadmap-wall.md) でのロードマップ壁打ちに使う。

## 使い方

1. 動画・覚書を見たら、既存メモの型に合わせて `docs/learning/<slug>.md` を追加（または短い追記）
2. この README の **履歴一覧** に1行足す
3. ロードマップに効く論点だけ [roadmap-wall.md](./roadmap-wall.md) の「いま / 近場 / 先」や壁打ちログへ反映
4. Cursor 等で壁打ちするときは、このフォルダと `roadmap-wall.md` を文脈に渡す

## ROADMAP への切り出し（移動しない）

このフォルダは **知識の置き場**。リポジトリ外や別ディレクトリへ移さない。

サイトや `tools/` に落とす成果だけ、**人間**が完了条件つきで [ROADMAP.md](../../ROADMAP.md)（Backlog → 必要なら Agent queue）へ昇格する。エージェントはここのチェックボックスを実装タスクとして消化しない。手順の詳細は [docs/harness-and-loop.md](../harness-and-loop.md) の「切り出し運用」。

## 共通の優先（全メモ共通）

1. **給料分の成果をちゃんと出す** — 学習が成果を削らない
2. **実務とスキル習得をなるべく兼ねる** — 仕事の改善がそのままスキルになる

両立できないときは目標1を優先する。行き先のイメージは個人事業向けスキル。投資助言や転職の確定方針ではない。

## 新規メモを足すとき

- ファイル名は短く英語スラッグ（例: `ai-plan-comparison.md`）
- 冒頭に「自分用メモ／公開サイトではない」と出典
- 動画の全文転記はしない。**要点マップ → 自分向けの読み → 次の一歩** を最小構成に
- 履歴一覧と、必要なら roadmap-wall の該当層だけ更新する
