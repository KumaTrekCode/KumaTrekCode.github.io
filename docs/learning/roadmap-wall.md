# ロードマップ壁打ち（生きたメモ）

> 公開サイト本文ではない。[学習メモ履歴](./README.md)を材料に、**いま → 近場 → 先** を壁打ちするための正本。結論を急がなくてよい。更新したら下の「壁打ちログ」に日付を残す。

## 壁打ちの使い方（Cursor 向け）

次をプロンプトに添えると続きやすい。

```text
docs/learning/ の履歴と roadmap-wall.md を前提に、ロードマップを壁打ちしたい。
優先は（1）給料分の成果（2）実務とスキルの兼ね。
今回聞きたいこと: （例: 今週の一手 / 近場のスキル順 / 本線AIツール / やらないこと）
断定や転職・投資の助言は不要。選択肢とトレードオフを短く。
```

## 北極星（ざっくり）

| 時間軸 | 行き先のイメージ |
|--------|------------------|
| いま（現職） | 実機評価・ECU計測で給料分の成果。自動化・説明力・再現性を実務に載せる |
| 近場 | ポータブルスキル（計測の言語化 / Python自動化 / Webで状況を見せる / AIエージェント協働）を成果と両立して積む |
| 先 | 個人事業向け。現場課題→実装の一気通貫、自動車×AI・情報収集の仕組み化。FIRE数字より **戻れる稼ぐ力** |

根拠メモ: `ai-automotive-news` / `ai-engineer-roles` / `fire-human-capital` / `work-wellbeing`

## いま / 近場 / 先（作業用）

### いま（今四半期）

- [ ] 本業の成果を削らない学習上限を守る（動画・メモは週の枠内）
- [ ] 計測まわりの小さな自動化を1本、再現可能な形で残す
- [ ] AIツールは本線1つに寄せる候補を決める（詳細は `ai-plan-comparison`）
- [ ] 「裁量 or 目的共感」があった業務を週1行だけ残す（`work-wellbeing`）

### 近場（半年イメージ）

- [ ] 職種マップ第1層の土台: Web（見せる）＋データ整形（綺麗な計測データ）＋ Linux で自分の道具を動かす
- [ ] 第2層の匂い: SET的な「同じ手順で繰り返せる品質」／コーポレートIT的な AI の安全な使い方
- [ ] ポータブルスキルを3つ以内に固定し、ポートフォリオか社内成果のどちらで証明するか決める
- [ ] サードプレイス1つ＋体力メンテ枠（気合依存をやめる）

### 先（個人事業・選択肢）

- [ ] 課題抽出→実装の小さな事例を積み、FDE／アプライドAI寄りの「戻れる力」にする
- [ ] 自動車×AIはタグ収集→実務翻訳の型が回ってから自動化を検討（`youtube-dashboard` は参考）
- [ ] 金融資産と年収の関係を時々確認。未満なら運用の小技より本業・貯蓄・人的資本（`fire-human-capital`）
- [ ] FIREや標準キャリアとの比較は材料に留め、自分の軸（成果・説明・自動化）で選ぶ

## やらないこと（壁打ちで崩さない）

- 学習・動画収集が本業成果を削ること
- 職種名収集・AIプラン比較・FIRE金額シミュレーションへの溺れ
- サードプレイスやツールの掛け持ち増やし
- 公開サイトを学習メモや FIRE 発信の場にすること

## 動画・覚書から拾った軸（横断）

| 軸 | 学び | ロードマップへの効き |
|----|------|----------------------|
| 人的資本 | 資産＜年収なら稼ぐ力が先 | 近場のスキル定義の最優先 |
| 職種4層 | 入口は第1層、最前線は経験後 | いまは土台。第4層は興味の方向づけのみ |
| ツール | 本線1＋不足だけ | エージェント協働の本線を決め打ちする |
| 自動車×AI | 成果へ翻訳して試す | 現職の精度・効率化ネタの供給源 |
| ウェルビーイング | 裁量 or 目的共感／体力／比較しない | 続けられるペースと居場所の設計 |

## 壁打ち用の問い（必要なら1つだけ）

1. 今週、本業成果に載る一手は何か？（載らないならやらない）
2. ポータブルスキル3つのうち、今四半期はどれを証明するのか？
3. AI本線ツールはどれか？二重課金や用途の重なりはないか？
4. 「やらないこと」に触れそうな誘惑は何か？
5. 先（個人事業）の話が、いまの成果を削っていないか？
